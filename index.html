做给中文开发者用的
Agent 工具。

我是独立开发者，也经常远程换地方写代码。 现在主要精力在 小桃子： 一套面向中文开发者的 AI Agent 工具线——CLI、插件、终端， 以及还在私有仓库里的桌面端和公众号智能体。

产品、工程到发布基本上自己闭环。 下面只列公开仓库；私有的部分有了稳定入口再放上来。

常用技术

TypeScript、Rust、Python、Vue；跑在 Node / Docker 上比较多。 工具侧主要是 Git 和 VS Code / Cursor 一类编辑器。 没有特别花哨的栈，能把 Agent 工作流跑顺就行。

在做

  • xiaotaozi-dsh

    小桃子 DSH 的公开主仓。 xtz CLI + DeepSeek Harness 插件， 覆盖模型服务商、IM、企业微信办公、侧栏工作台和小桃子市场。

  • tzWarp

    中文 AI 终端，Rust 实现，基于开源 Warp。 直连小桃子中转，命令先出卡片，确认后再执行。

  • pi-plugins

    Pi 生态的一等公民插件与精选目录， 含飞书 IM 等 first-party package。

  • taozi-plugin

    Claude Code / Codex 插件工具集： 工作流、Skills、Hooks，以及一些 AI 创作向能力。

  • skills

    公开的 Agent Skill 孵化器。 成熟一点的 skill 会拆成独立仓库发版。

可直接装的 Skills

  • tzai-image-skill

    经 TaoziAPI 做自然语言生图 / 视觉项目。

  • wechat-mp-skill

    微信公众号成稿 + 本地预览，可选草稿箱。

  • lark-push-skill

    飞书 / Lark 进度、日报、发布通知。

npx skills add kedoupi/tzai-image-skill -g --all
npx skills add kedoupi/wechat-mp-skill
npx skills add kedoupi/lark-push-skill

顺手

    股票监控工作台：美股 + A 股实时行情、 多档 Telegram 告警，Docker 一键部署。
